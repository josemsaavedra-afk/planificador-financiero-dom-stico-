PLANIFICADOR FINANCIERO FAMILIAR — VERSIÓN CLOUD

Esta versión usa directamente el proyecto Supabase existente y NO guarda los movimientos financieros en localStorage.

Incluye:
- dos usuarios con email/contraseña;
- hogar compartido con código de invitación;
- sincronización y refresco entre dispositivos;
- Hoy y pendientes;
- calendario perpetuo;
- movimientos y recurrencias;
- ingresos y prefinanciación;
- tesorería 10/25 editable;
- personas y bancos editables;
- importación de los 209 movimientos del Excel original.

IMPORTANTE: para abrirla como app compartida en dos iPhone debe publicarse en un alojamiento HTTPS estático. El archivo index.html ya está listo para ello. No hace falta Lovable.

La publishable key incluida es una clave pública diseñada para aplicaciones web. La seguridad real de los datos la aplican las políticas RLS de Supabase.
